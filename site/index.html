Your business, as a file.

Serigraph keeps a company's operating model in one YAML file. Humans get a zoomable map. Agents get the truth.

Clone and run Read the format

Edit the map or edit the file. Same thing.

Every drag, rename, and connection writes the smallest possible change to the YAML. Hand-written comments survive every edit. git diff shows exactly what changed about how the business runs, line by line.

- id: first-contact type: process label: First contact cost: runs: 260 human: {minutes: 9, rate: 42} agent: {perRun: 0.18, setup: 900}
the same seven lines, rendered

Paste the discovery call. Review what it heard.

The importer builds the map only from what was said. Hedged or implied items carry a flag in the file itself, and on the canvas, until you confirm or correct them. A transcript with no process in it gets an error, not an invented map.

the client says
Karen: Marisol runs the verifications every morning for anyone coming in the next... I think she works two days out?
the file records
- id: insurance-verification # uncertain: "two days out" was Karen's guess
the canvas shows
⚑ uncertain · "two days out" was Karen's guess ✓ Mark confirmed

The model call happens server side. Keys never reach the browser, the YAML, or an export. Point it at the Anthropic API, at any local model over stdin, or at nothing: the app runs fully offline with the importer switched off.

The same file prices the automation.

Give any step a run count, minutes, and a rate, then what an agent costs per run. The rollup recomputes live as you type, in the file and on the canvas.

Computed from 2 of 23 steps costed so far, and the bar says so. Steps with missing inputs stay out of every total: a blank is a blank, never a zero.

Agents read the same file. Next, they propose to it.

A map is a contract: five node types, validated structure, stable ids, provenance flags. An LLM agent can already read and write every map here, and its change arrives as a text diff a human can review.

The roadmap runs one direction: propose, approve, audit. The operating model stays governed while agents take on more of the operating.

House rules

The file is the truth.
The canvas is a view. Any editor, any agent, any diff tool works on the real thing.
Unknown is never zero.
Missing inputs exclude a step from every total. Coverage is always stated.
Never fabricate.
Imported items the transcript only implies are flagged with the reason for doubt.
Secrets stay server side.
No key in the browser, the YAML, or an export. Offline is a feature, not a failure.
Zero runtime dependencies.
Two vendored libraries. No install, no build. Clone and run must survive years.
Structure over styling.
Five node types, and only five. A curated vocabulary is what keeps maps machine-readable.
